# 新闻传播学答题模板

适用：新闻学、传播学、网络与新媒体、广告学、广播电视学等。

## 目录

- 题型总览
- 传播学名词解释
- 理论论述题
- 现象与热点分析题
- 新闻实务题
- 记忆策略与训练类型

以下分值、字数、时间和结构是通用训练参考，不代表用户所在考试的评分规则。精确理论元数据与当下案例须来自用户材料或经权威来源核验。

## 题型总览

| 题型 | 分值 | 字数 | 时间 | 核心骨架 |
|------|------|------|------|---------|
| 传播学名解 | 3-5 | 150-300 | 5min | 提出者+时间+著作→核心定义→要点→评价/发展 |
| 理论论述 | 20-30 | 800-1200 | 25-30min | 内涵→发展脉络→现实解释力→局限→新媒体变迁 |
| 现象/热点分析 | 20-30 | 800-1200 | 25-30min | 现象→理论工具→5W或分层分析→趋势判断 |
| 消息写作 | 15-20 | 500-800 | 15-20min | 标题→导语→正文（倒金字塔） |
| 新闻评论 | 20-25 | 800-1000 | 20-25min | 由头→论点→论证→收束 |
| 采访/策划 | 15-25 | 600-800 | 18-22min | 主题→对象+问题→报道形式→注意事项 |

## 传播学名词解释（3-5分，150-300字）

```text
提出者+时间+著作：XX 年，[学者名] 在《[著作名]》/《[期刊名]》上提出
核心定义：该理论认为/指……（一句话精准概括）
理论要点（2-3个）：
  （1）……
  （2）……
  （3）……
评价/发展：该理论开创了……研究范式 / 将效果研究从……转向……；
           在新媒体环境下，发展为…… / 面临……的挑战
```

提出者、年份、著作、核心定义、理论要点与评价是常见信息维度，但具体评分取决于题目和评分细则。核心定义通常比装饰性信息更重要；不能确认年份或著作时应标记待核验，不要猜写。

**结构示范**：
> `[待核验：提出者]` 于 `[待核验：时间]` 在 `[待核验：文献]` 中提出该理论。其核心命题是 `[依据教材准确概括]`。理论包含 `[要点一]`、`[要点二]` 和 `[要点三]`。它把研究视角推进到 `[理论意义]`；在新媒体环境下，还需要讨论 `[适用边界或发展]`。

不要直接把结构示范中的占位符补成记忆中的人名、年份或文献；先从用户材料定位，或通过权威来源核验。

## 理论论述题（20-30分，800-1200字）

```text
第一段：理论内涵——谁、何时、什么背景下提出，核心命题，所属研究范式
第二段：发展脉络——后续学者的修正/补充/批判，理论自身的演变路径
第三段：现实解释力（40%，核心得分段）——
        用 1-2 个能够准确陈述、与理论机制直接相关的媒介事件或现象解读
第四段：理论局限——不适用条件？忽略的变量？文化特殊性？
第五段：新媒体变迁——互联网/社交媒体/算法时代，理论如何修正？
```

---

## 现象/热点分析题（20-30分，800-1200字）

```text
第一段：现象描述——什么事件/趋势，有什么传播学特征
第二段：理论工具选择——"本文拟用 XX 理论和 YY 理论"，简述理由

第三段：多维度分析（60%，核心得分段）

  框架 A — 5W（拉斯韦尔）：
  - 传播者（Who）：谁在传播？动机？可信度？立场？
  - 内容（Says What）：内容特征？框架策略？话语特征？
  - 媒介（In Which Channel）：平台特性？算法机制？媒介对内容的反塑？
  - 受众（To Whom）：受众特征？使用动机？满足情况？
  - 效果（With What Effect）：认知/态度/行为影响？

  框架 B — 分层：
  - 微观层：个体传播行为与心理
  - 中观层：组织/社群/媒体的传播运作
  - 宏观层：社会结构、文化规范、政策环境

第四段：趋势判断——演变方向 / 对新闻传播实践的启示
```

**理论组合速查**：

| 分析对象 | 推荐理论组合 |
|---------|------------|
| 生产端（谁在生产内容） | 把关人 + 框架理论 + 新闻生产社会学 |
| 内容端（内容本身） | 话语分析 + 符号学 + 叙事理论 |
| 受众端（谁在接受） | 使用与满足 + 选择性接触 + 第三人效果 |
| 效果端（产生了什么影响） | 议程设置 + 涵化理论 + 知沟/数字鸿沟 |
| 技术端（媒介本身） | 媒介即讯息 + 媒介生态学 + 技术可供性 |

## 新闻实务题

### 消息写作（15-20分）

```text
标题：实题，≤15字，包含核心新闻要素。不做评论
导语：≤80字，最有新闻价值的要素前置，浓缩关键 5W
正文（2-4段）：最重要事实 → 次重要信息/引语 → 背景/次要信息
语言：客观陈述，多用动词，不用"据悉""据了解"，不用主观形容词
```

### 新闻评论（20-25分）

```text
由头：一句话引入新闻事件，快速过渡到观点
中心论点：犀利、明确、有态度，15 字以内
论证（2-3层）：每层 = 分论点 → 事实论据 → 道理论据 → 回扣
收束：回扣论点 + 行动建议或深层追问。不说"综上所述"。有力短句收尾
```

### 采访提纲/报道策划（15-25分）

```text
一、报道主题与新闻价值（一句话）
二、采访对象及理由（≥3类，体现多元视角）
   - 对象 1：[类型]，理由：……
     问题（5-8个，从开放到聚焦）：1.…… 2.…… 3.……
   - 对象 2、3：（同上结构）
三、报道形式与发布渠道（是否需要融媒体方案以题目要求为准）
四、注意事项：伦理（隐私/知情同意/最小伤害）
              法律（名誉权/著作权/未成年人保护）
              操作风险（采访拒绝/信息真实性）
```

## 记忆策略

**三锚定位法**：每个理论锁三个锚点——人名、时间+著作、一句话核心。遗忘任何一个可从其他两个回溯。

**热点挂钩法**：每个理论储备 1-2 个当下热点事件。论述题的核心能力是"用理论解读现象"。

**效果研究纵向线**（用于组织教材内容，不代表固定分期）：

```text
早期强效果观点 → 有限效果研究 → 效果研究的再认识
→ 新媒体环境下的互动、协商与平台化效果研究
```

具体阶段名称、年代、代表学者和理论归属以课程材料为准。复习时重点解释“为什么研究判断发生变化”，再记忆经核验的元数据。

**学者-理论配对表**：新传有大量以人名命名的理论/概念，做一个配对表每天速览。

## 训练类型

- **理论五要素默写**（5min/题）：给理论名称→写出提出者+时间+著作+定义+要点+评价/发展
- **热点理论速配**（5min）：给时事热点→列出 2-3 个分析理论+切入说明
- **5W 框架速套**（10min）：给媒介现象→按 5W 写出分析提纲（每个 W 2-3 要点）
- **消息导语速写**（5min）：给 200-300 字素材→标题（≤15字）+导语（≤80字）
- **评论框架速构**（8min）：给新闻事件→由头+中心论点+3 个分论点标题+论据关键词
